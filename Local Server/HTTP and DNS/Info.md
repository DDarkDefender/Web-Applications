##  Building a small HTTP + DNS OOB listener with Python

Use Python's dnslib package:
`pip install dnslib`

Download [listener.py](https://github.com/DDarkDefender/Web-Applications/blob/main/Local%20Server/HTTP%20and%20DNS/listener.py)

Run the listener using:
`python3 listener.py`

> [!IMPORTANT]
> This is a listener, not a full Collaborator replacement. In particular, it doesn't provide automatic DNS delegation for an arbitrary hostname.
